# Nookery

[English](README.md) | 简体中文

Windows 11 桌面磁贴。桌面上的散文件（文件夹、文档、图片等）会自动按类型收进对应的磁贴，快捷方式留在桌面不动。

- 单个约 430 KB 的 exe，常驻私有内存 12~14 MB，空闲时 CPU 为 0。
- 磁贴透明度五档可调，最高全透明只留一圈淡边框；跟随系统深浅色。
- 文件图标用系统原版图标，和资源管理器里看到的一样。
- 界面支持中文和英文。

调研、方案对比和实测数据见 [docs/调研与方案.md](docs/调研与方案.md)。

## 安装

到 [Releases](https://github.com/ArthurLauCS/Nookery/releases/latest) 下载 `Nookery-Setup-<版本>.exe` 运行，需要 Windows 11。

- 安装包没有商业代码签名证书，Windows 可能提示“Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
- 安装过程中会弹一次管理员权限确认，用来给桌面右键菜单装签名证书；拒绝的话程序照常能用，只是“新建磁贴”要到“显示更多选项”里找。
- 第一次运行会先告诉你要收进多少项，确认后才整理。

## 构建

```bash
cargo build --release
```

产物在 `target/release/nookery.exe`，需要 Rust 工具链和 MSVC 生成工具。

安装包（需要 [Inno Setup 6](https://jrsoftware.org/isdl.php) 和 Windows SDK）：

```bash
powershell -File scripts/installer.ps1
```

先编译 release（含右键菜单扩展 `menu/`），把 `installer/AppxManifest.xml` 打成稀疏包并签名，再按 `Cargo.toml` 的版本号打包到 `target/installer/Nookery-Setup-<版本>.exe`。签名用当前用户证书库里的自签证书 `CN=Nookery`，没有会自动新建。

安装包：

- 开头选中文或英文，同时也是程序的界面语言。
- 按当前用户安装到 `%LOCALAPPDATA%\Programs\Nookery`。
- 只有一步要管理员权限：把签名证书装进本机“受信任人”，Win11 才认这个稀疏包，桌面右键菜单第一级才有“新建磁贴”。证书装过后升级不再弹 UAC；卸载时删证书，会再弹一次。
- 可选开机自启和桌面快捷方式；升级时会自动结束正在运行的程序。

脚本在 `installer/nookery.iss`，简体中文界面文本 `installer/ChineseSimplified.isl` 取自 Inno Setup 官方仓库的非官方翻译。

应用图标的源文件是 `assets/icon.svg`（40px 及以上）和 `assets/icon-small.svg`（16～32px）。改完运行 `python scripts/icon.py` 重新生成 `assets/app.ico` 和 `assets/app.res`（需要 Chrome、Pillow 和 Windows SDK），`build.rs` 把它链接进 exe。

## 文件放在哪

- 归进磁贴的文件实际移到 `桌面\.Nookery\<磁贴名>\`。这个目录带隐藏和系统属性。文件路径会变，但文件仍在桌面目录下，OneDrive 桌面同步照常生效。
- 配置在 `%APPDATA%\Nookery\config.txt`：磁贴位置、锁定、折叠、规则、透明度、暂停状态。
- 在 `.Nookery` 里手动建一个文件夹，它也会变成一块磁贴。
- 第一次在真实桌面上运行时，会先告诉你要收进多少项，确认后才整理。选“否”就先暂停自动归类。
- 用安装包装的，卸载时会自动结束程序、把文件全部放回桌面，并删掉开机自启、桌面右键菜单里的“新建磁贴”、签名证书、语言设置和配置。直接运行 exe 的，卸载前在托盘菜单里点“全部还原到桌面”。

## 归类规则

| 磁贴 | 内容 |
|---|---|
| 文件夹 | 目录 |
| 文档 | doc docx pdf txt md rtf odt xls xlsx csv ppt pptx wps et dps |
| 图片 | png jpg jpeg gif webp bmp svg heic ico psd |
| 视频 | mp4 mkv mov avi wmv flv webm |
| 音频 | mp3 wav flac aac m4a ogg |
| 压缩包 | zip rar 7z tar gz |
| 程序 | exe msi |
| 其他 | 以上都不是的 |

不归类、留在桌面的：

- 快捷方式（`.lnk` `.url` `.appref-ms` `.website`）
- 隐藏文件和系统文件
- 下载中的临时文件（`.crdownload` `.part` 等）
- Office 锁文件（`~$` 开头）

文件要 3 秒内没有改动、并且能独占打开才会移走；你正在桌面上给图标改名时也不移。

- **改规则**：把某种文件从一块磁贴拖到另一块，会问你以后这种扩展名是否都放进新磁贴。
- **拖回桌面**：从磁贴拖回桌面的文件会留在桌面，不再被收回去（记在配置的 `keep` 里）。把它删掉或改名后，这条记录自动清掉。

## 磁贴标题栏

- 名字居中。单击名字进入改名，点别处或按 Enter 保存，Esc 取消。
- 按住标题栏拖动就是移动磁贴。
- 右上角两个按钮，鼠标移到磁贴上时显示：
  - 折叠 / 展开。
  - 锁定 / 解锁：锁定后不能拖动、不能改尺寸，仍可改名。
- 锁住的磁贴一直显示锁图标，折叠的磁贴一直显示展开箭头。

## 透明度

托盘菜单“磁贴透明度”里选，所有磁贴一起变：

| 档位 | 效果 |
|---|---|
| 100% / 75% / 50% | 亚克力磨砂，档位越低底色越薄 |
| 25% | 半透明底色，背后不模糊 |
| 0% | 全透明，只留一圈淡边框（外白内黑，深浅壁纸上都看得出）；鼠标移到磁贴上时淡淡显出底色 |

50% 及以下文字直接压在壁纸上，会改成桌面图标那样的白字加四周暗边。

## 语言

中文 / 英文，在托盘菜单“语言/Language”里切换（选项是“中文/Chinese”和“English”，切到哪种语言都认得出入口），存在 `HKCU\Software\Nookery` 的 `Language`；没设过时跟随系统界面语言。切换后：

- 菜单、提示、对话框立即换语言。
- 默认磁贴（文件夹、文档、图片……）连同目录一起改成对应语言的名字；改过名的和新建的磁贴不变，新名字已被占用的那块也不改。
- 桌面右键菜单里的“新建磁贴”跟着换。

## 操作

| 操作 | 效果 |
|---|---|
| 双击文件 / Enter | 打开 |
| 方向键 / Home / End | 移动选中项（显示键盘焦点环） |
| 右键文件 | 系统右键菜单 |
| F2 | 改名 |
| Delete（Shift+Delete） | 删到回收站（彻底删除） |
| Ctrl+A / C / X / V | 全选 / 复制 / 剪切 / 粘贴 |
| 拖出 / 拖入 | 和资源管理器一样，同盘移动、跨盘复制；按住 Ctrl 复制、Shift 移动；拖到磁贴上时磁贴高亮 |
| 在磁贴内拖动图标 | 调整顺序，落点处显示一条竖线；顺序会记住 |
| 把此电脑、回收站等从桌面拖进磁贴 | 磁贴里建对应的快捷方式，桌面上的原图标隐藏；快捷方式离开所有磁贴后（删掉、拖回桌面、删磁贴、全部还原、卸载）原图标恢复 |
| 拖标题栏 | 移动到任意位置；靠近屏幕边缘或其他磁贴 8px 内会吸附，按住 Alt 不吸附 |
| 拖边缘 | 改尺寸，同样吸附；最小一行图标高 |
| 右键标题栏或空白处 | 在资源管理器中打开、删除磁贴 |
| 桌面空白处右键 → 新建磁贴 | 在右键的位置新建一块磁贴并进入改名。用安装包装的在 Win11 右键菜单第一级；直接运行 exe 的只在“显示更多选项”（或 Shift+右键）里 |
| 双击桌面空白处 | 隐藏 / 显示全部磁贴，并在双击处上方弹出提示 |
| 左键单击托盘图标 | 隐藏 / 显示全部磁贴 |
| 右键托盘图标 | 新建磁贴、隐藏磁贴、双击桌面空白处隐藏磁贴（开关）、暂停自动归类、磁贴透明度、全部还原到桌面、开机自启、语言、退出 |

资源管理器重启后磁贴会自动重建。

## 测试

```bash
cargo test
```

`scripts/` 下是用假桌面做的端到端测试，不会碰真实桌面：

- `setup.ps1`：在 `C:\WorkFile\Temp\fakedesk` 造一批测试文件；加 `-Bulk 200` 再多造 200 个。
- `run.ps1`：用 `--root` 指向假桌面启动，检查归类结果、内存和 CPU，并截图。
- `interact.ps1`：借助 `examples/drive.rs` 给磁贴窗口发消息，测选中、F2 改名、折叠按钮，以及拖回桌面的文件留在桌面。
- `design.ps1 -Round N`：设计走查取证。先用 `backdrop.ps1` 铺一张花哨的假壁纸，再截以下几组状态，外加去色版：
  - 深色 100 / 75 / 50 / 25 / 0% 和浅色 100%。
  - 锁定、折叠、选中。
  - 单击名字改名、双击隐藏的提示、第二个进程 `--new-tile`。
- `contrast.ps1`：算主题配色在最坏背景下的对比度。

启动参数：

| 参数 | 用途 |
|---|---|
| `--root <目录>` | 用指定目录代替桌面，配置也存进那个目录 |
| `--top` | 磁贴置顶，便于截图 |
| `--light` / `--dark` | 强制主题 |
| `--new-tile` | 在鼠标处新建磁贴；已在运行时转给正在运行的实例 |
| `--uninstall` | 把文件全部放回桌面，删掉开机自启和右键菜单后退出（卸载程序调用，调用前要先结束正在运行的实例）；配合 `--root` 可在假桌面上测试 |
